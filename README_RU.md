# Mouser — Настройка и переназначение кнопок мышей Logitech

<p align="center">
  <img src="images/logo_icon.png" width="128" alt="Логотип Mouser" />
</p>

[English](README.md) | Русский | [中文文档](README_CN.md)

Легковесная, открытая и **полностью локальная** альтернатива **Logitech Options+** для переназначения кнопок и жестов мышей Logitech HID++. Наилучшим образом поддерживает семейства **MX Master** и **MX Anywhere**, а также предоставляет определение и универсальный интерфейс для других моделей Logitech.

**Без телеметрии. Без облака. Без аккаунта Logitech.**

1. Откройте [**страницу последнего релиза**](https://github.com/TomBadash/Mouser/releases/latest).
2. Скачайте zip-архив для вашей системы:
   - **Windows** — `Mouser-Windows.zip`
   - **macOS (Apple Silicon)** — `Mouser-macOS.zip`
   - **macOS (Intel)** — `Mouser-macOS-intel.zip`
   - **Linux** — `Mouser-Linux.zip`
3. Распакуйте в любую папку (Рабочий стол, Документы, `/Applications` и т. д.).
4. Запустите исполняемый файл: `Mouser.exe`, `Mouser.app` или `./Mouser`.

Вот и всё. Приложение откроется, добавит иконку в системный трей / строку меню и сразу начнёт переназначение.

### Чего ожидать при первом запуске

- Окно настроек откроется на странице **Мышь и профили**.
- Появится иконка в трее (рядом с часами на Windows / Linux, в строке меню на macOS).
- При закрытии окна Mouser продолжает работать в трее. Для полного выхода нажмите правой кнопкой по иконке в трее → **Выйти из Mouser**.
- Mouser запоминает выбор языка и настройки автозапуска между запусками.

### Важные примечания при первом запуске

- **Windows SmartScreen** может выдать предупреждение при первом запуске — нажмите **Подробнее** → **Выполнить в любом случае**.
- **Logitech Options+ не должен быть запущен.** Обе программы конфликтуют за доступ к HID++; закройте Options+ перед запуском Mouser.
- **macOS** запрашивает разрешение **Универсальный доступ** (Accessibility) для перехвата событий мыши. Подробную инструкцию см. в [readme_mac_osx.md](readme_mac_osx.md).
- **Linux** требуется доступ на чтение к `/dev/hidraw*`, `/dev/input/event*` и запись в `/dev/uinput`. Запустите скрипт из архива один раз:
  ```bash
  cd /path/to/extracted/Mouser
  ./install-linux-permissions.sh
  ```
  Переподключите мышь и перезапустите приложение.
- Конфигурация автоматически сохраняется в:
  - `%APPDATA%\Mouser\config.json` (Windows)
  - `~/Library/Application Support/Mouser/config.json` (macOS)
  - `~/.config/Mouser/config.json` (Linux)
- Логи ротируются автоматически (5 × 5 МБ) в `%APPDATA%\Mouser\logs`, `~/Library/Logs/Mouser` или `$XDG_STATE_HOME/Mouser/logs`.

## Возможности

### Переназначение кнопок

- **Переназначение любых настраиваемых кнопок** — средняя кнопка, кнопка жестов, «Назад», «Вперёд», смена режима, переключатель DPI (MX Vertical) и горизонтальная прокрутка.
- **Переназначение кнопки мыши на другую кнопку** — привязка любой кнопки на выполнение левого, правого, среднего кликов или кнопок «Назад» / «Вперёд».
- **Профили для отдельных приложений** — Mouser автоматически переключает профили при смене активного окна (например, Chrome vs. VS Code).
- **Свои сочетания клавиш** — запись любых комбинаций (например, `Ctrl+Shift+P`) прямо в интерфейсе.
- **Более 40 встроенных действий** — навигация, браузер, редактирование, медиа, режимы прокрутки и DPI с адаптацией под операционную систему.

### Управление устройством

- **DPI / скорость указателя** — ползунок от 200 до максимума устройства (8000 на MX Master) с быстрыми пресетами и действием `Циклическое переключение пресетов DPI`.
- **Smart Shift** — переключение режима колеса прокрутки пошаговый ↔ свободный (HID++ `0x2111`) с порогом чувствительности и привязываемым действием `Переключить SmartShift`.
- **Переключение режима колесика** — назначение кнопки на смену режима без открытия интерфейса (по умолчанию на кнопку смены режима).
- **Инверсия направления прокрутки** — независимые переключатели для вертикальной и горизонтальной прокрутки.
- **Кнопка жестов и свайпы** — нажатие для одного действия, свайпы вверх/вниз/влево/вправо для четырех других.

### Кроссплатформенность

- **Windows, macOS и Linux** — нативные хуки для каждой платформы (`WH_MOUSE_LL`, `CGEventTap`, `evdev` + `uinput`).
- **Нативные сборки macOS для Intel и Apple Silicon** — отдельные архивы `Mouser-macOS-intel.zip` и `Mouser-macOS.zip`; приложение в строке меню работает как `LSUIElement` (без иконки в Dock).
- **Масштабируемый интерфейс** — главное окно открывается в размере 1060 × 700 с минимумом 920 × 620; схема мыши и элементы гибко адаптируются при изменении размера.
- **Автозапуск при входе** — реестр Windows, LaunchAgent macOS и XDG autostart Linux с опцией **Запускать свёрнутым** прямо в трей.
- **Защита от повторного запуска** — запуск второй копии разворачивает существующее окно.

### Умное подключение

- **Bluetooth и Logi Bolt** — поддержка обоих типов подключения на всех трех платформах.
- **Автоматическое переподключение** — отслеживание выключения/включения мыши и повторная привязка HID++ и хуков без перезапуска программы; настройки SmartShift повторно применяются после каждого переподключения, включая пробуждение из сна.
- **Статус подключения в реальном времени** — статус Подключено / Не подключено, имя модели и активная раскладка в интерфейсе.
- **Интерактивные схемы устройств** — наглядные схемы MX Master и MX Anywhere с интерактивными точками; универсальная карточка для других моделей.

### Многоязычный интерфейс

- **Английский / Упрощенный китайский / Традиционный китайский / Русский** — мгновенное переключение языка без перезапуска приложения.
- Выбранный язык сохраняется в `config.json` и восстанавливается при следующем запуске.
- Переведены навигация, страница мыши, настройки, диалоги, системный трей / строка меню и запросы разрешений.

### Конфиденциальность прежде всего

- **Полностью локальная работа** — конфигурация хранится в обычном JSON-файле, вся обработка выполняется на вашем компьютере.
- **Системный трей / строка меню** — приложение незаметно работает в фоновом режиме.
- **Нулевая телеметрия, без облака и без обязательного аккаунта.**

| MX Master 4 / 3S / 3 / 2S / MX Master | Да | Интерактивные схемы для каждой модели |

## Доступные действия

Названия действий адаптируются под платформу. В Windows доступны `Win+D` и «Представление задач»; в macOS — Mission Control, «Показать рабочий стол», App Exposé и Launchpad; в Linux используются нативные эквиваленты оконного менеджера.

| Категория | Действия |
|---|---|
| **Навигация** | Alt+Tab, Alt+Shift+Tab, Показать рабочий стол, Предыдущий рабочий стол, Следующий рабочий стол, Представление задач (Windows), Mission Control / Exposé / Launchpad (macOS), Page Up / Page Down / Home / End |
| **Браузер** | Назад, Вперёд, Закрыть вкладку (Ctrl+W), Новая вкладка (Ctrl+T), Следующая вкладка (Ctrl+Tab), Предыдущая вкладка (Ctrl+Shift+Tab) |
| **Редактирование** | Копировать, Вставить, Вырезать, Отменить, Выделить всё, Сохранить, Найти |
| **Медиа** | Увеличить громкость, Уменьшить громкость, Отключить звук, Воспроизведение / Пауза, Следующий трек, Предыдущий трек |
| **Прокрутка** | Сменить режим колеса (Пошаговый / Свободный), Переключить SmartShift, Циклическое переключение пресетов DPI |
| **Мышь** | Левый клик, Правый клик, Средний клик, Назад (Кнопка 4), Вперёд (Кнопка 5) |
| **Свои** | Пользовательские комбинации клавиш (записываемые в UI) |
| **Разное** | Ничего не делать (без изменений) |

## Сборка из исходного кода

Этот раздел нужен, если вы хотите разрабатывать Mouser или запускать development-сборку. Большинству пользователей лучше скачать zip-архив релиза — см. [Скачивание и запуск](#скачивание-и-запуск).

### Общие требования

- **Windows 10/11**, **macOS 12+ (Monterey)** или **Linux** (X11; для определения приложений в KDE Wayland).
- **Python 3.10+** (проверено до 3.14).
- Поддерживаемая мышь Logitech HID++, подключенная по Bluetooth или через USB-ресивер.
- **Logitech Options+ не должен быть запущен** — он конфликтует за доступ к HID++.
- `git` и рабочий набор инструментов сборки.

```bash
git clone https://github.com/TomBadash/Mouser.git
cd Mouser
python -m venv .venv
```

<details>
<summary><strong>Windows</strong></summary>

```powershell
.\.venv\Scripts\activate
pip install -r requirements.txt

# Запуск из исходного кода
python main_qml.py

# Или сразу в трей
python main_qml.py --start-hidden

# Сборка переносимого zip-архива
build.bat                # обычная сборка
build.bat --clean        # принудительная чистая сборка
```

`build.bat` устанавливает зависимости, проверяет импорт `hidapi` и собирает приложение через PyInstaller. Результат находится в `dist\Mouser\` — заархивируйте эту папку для распространения.

Чтобы запустить исходный код без консольного окна, создайте ярлык, использующий `pythonw.exe`; см. [DEVELOPMENT.md](DEVELOPMENT.md#desktop-shortcut-windows).

</details>

<details>
<summary><strong>macOS</strong></summary>

```bash
source .venv/bin/activate
pip install -r requirements.txt

# Запуск из исходного кода
python main_qml.py
python main_qml.py --start-hidden     # запуск сразу в строку меню

# Сборка нативного приложения строки меню
pip install pyinstaller
./build_macos_app.sh
```

Результат — `dist/Mouser.app`. Скрипт использует `images/AppIcon.icns`, если файл существует, иначе создаёт иконку из `images/logo_icon.png`. Подпись зависит от переменной окружения `MOUSER_SIGN_IDENTITY`:

- **Не задана (по умолчанию):** выполняется ad-hoc-подпись через `codesign --sign -`. Это удобно для разовой сборки, но после пересборки macOS может снова запросить Accessibility-разрешение.
- **Содержит identity для codesigning** (`security find-identity -v -p codesigning` выводит доступные варианты; предпочтительна форма SHA-1): скрипт подписывает все вложенные `.dylib` / `.so` / `.framework` с hardened runtime, а затем внешнее приложение с исключениями hardened runtime из `build_resources/Mouser.entitlements`. Это путь локальной разработки для повторяющихся сборок; стабильность разрешений macOS зависит от неизменности исходников, интерпретатора Python, версий зависимостей, архитектуры, identity, entitlements и политики timestamp. Ошибка `codesign --verify --deep --strict` прерывает сборку.

```sh
MOUSER_SIGN_IDENTITY="ABCD1234..." ./build_macos_app.sh   # локальная подписанная сборка
```

- Это **не** процесс нотариальной подписи релиза. Публичные zip-архивы macOS используют ad-hoc-подпись, пока не появится отдельный процесс Developer ID, secure timestamp, notarization, stapling и проверки Gatekeeper.
- Собирайте на той архитектуре, которую хотите распространять: Python `arm64` создаёт Apple Silicon bundle, `x86_64` — Intel bundle. Для переопределения используйте `PYINSTALLER_TARGET_ARCH=arm64|x86_64|universal2`.
- CI автоматически публикует `Mouser-macOS.zip` (Apple Silicon) и `Mouser-macOS-intel.zip` (Intel) при публикации тегов.
- Требуется разрешение Accessibility. Полный порядок выдачи разрешения и примечания для платформы приведены в [readme_mac_osx.md](readme_mac_osx.md).

</details>

<details>
<summary><strong>Linux</strong></summary>

```bash
source .venv/bin/activate
pip install -r requirements.txt

# Запуск из исходного кода
python main_qml.py

# Установка разрешений для устройств (нужна один раз, затем переподключите мышь)
./packaging/linux/install-linux-permissions.sh

# Сборка переносимого bundle
sudo apt-get install libhidapi-dev
pip install pyinstaller
pyinstaller Mouser-linux.spec --noconfirm
```

Скрипт устанавливает `69-mouser-logitech.rules`, перезагружает `udev` и пытается выполнить `modprobe uinput`. После успешного запуска переподключите мышь, полностью закройте Mouser и запускайте его как обычно — без `sudo`. В системах без logind / `uaccess` запасной вариант, зависящий от дистрибутива, — добавить пользователя в группу `input`.

При первом обычном запуске Linux создаётся или обновляется:

```text
~/.local/share/applications/io.github.tombadash.mouser.desktop
```

Созданный launcher использует абсолютные пути к текущей переносимой версии или исходному каталогу и, когда возможно, синхронизирует иконку Mouser с пользовательской темой иконок hicolor. Если переместить каталог, один раз запустите Mouser из нового расположения, чтобы обновить пункт меню приложений. Включение **Запускать при входе в систему** также управляет файлом:

```text
~/.config/autostart/io.github.tombadash.mouser.desktop
```

Этот autostart-файл добавляет небольшую задержку запуска в GNOME, чтобы Mouser не конфликтовал с инициализацией Bluetooth / HID сразу после входа в систему.

`xdotool` обеспечивает переключение профилей по приложениям в X11; `kdotool` добавляет поддержку KDE Wayland. В других Wayland-композиторах используется профиль по умолчанию.

</details>

## Ограничения

- **Настройки для разных устройств пока не полностью разделены** — переопределения раскладки хранятся для каждого найденного устройства, но профильные назначения пока общие.
- **Конфликт с Logitech Options+** — приложения конкурируют за доступ к HID++. Перед запуском Mouser закройте Options+.
- **Инверсия прокрутки** в Windows использует объединённую отправку событий после injection, чтобы избежать deadlock в LL-hook; это стабильно в обычных приложениях, но может вести себя некорректно в некоторых играх или низкоуровневых драйверах.
- **Права администратора не требуются**, но внедрённые нажатия клавиш могут не доходить до окон с повышенными правами или некоторых игр. При необходимости запускайте Mouser с повышенными правами.
- **Определение приложений в Linux частичное** — X11 работает через `xdotool`, KDE Wayland через `kdotool`; в GNOME и других Wayland-композиторах используется профиль по умолчанию.
- **Разрешения Linux для устройств** — Mouser нужен доступ к `/dev/hidraw*`, `/dev/input/event*` и `/dev/uinput`. Один раз запустите [`install-linux-permissions.sh`](packaging/linux/install-linux-permissions.sh), а не запускайте приложение от root.
